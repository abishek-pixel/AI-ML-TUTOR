## Recording Tips

1. **Preparation:**
   - Have app running locally or on Spaces
   - Pre-test all features to ensure they work
   - Prepare a neural network diagram for upload
   - Keep demo crisp and fast-paced

2. **Recording:**
   - Use screen recording software (OBS, Loom, etc.)
   - Record at 1920x1080 resolution
   - Use clear audio (external microphone recommended)
   - Keep cursor movements smooth
   - Pause slightly between sections

3. **Editing:**
   - Speed up waiting times (API calls)
   - Add text overlays for key points
   - Include transitions between sections
   - Target 2:00-2:30 final length

4. **Key Points to Emphasize:**
   - Multi-level explanations (school, UG, expert)
   - Three prompt techniques compared
   - Fact-checking with confidence scores
   - Multimodal capabilities (text, image, audio)
   - Responsible AI safeguards

5. **Common Issues:**
   - If API is slow, edit out wait time
   - If model fails to load, show placeholder functionality
   - Keep explanations concise
   - Focus on demonstrations, not code
